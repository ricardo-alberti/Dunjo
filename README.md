# Dunjo

2D platformer game prototype built using SFML.

![image](dunjo.png)
---
## prerequisites
- **C++ compiler** supporting C++17 or later.
- **CMake** (version 3.10 or higher).
- **SFML** (version 3.0).  
---
## build instructions
```
git clone https://github.com/ricardo-alberti/Dunjo
cd Dunjo
mkdir out
cd out
cmake ..
make
./Dunjo
```
## useful resources:
- tileset by Arks: https://arks.itch.io/dungeon-platform-tileset/
- SFML: https://www.sfml-dev.org/
